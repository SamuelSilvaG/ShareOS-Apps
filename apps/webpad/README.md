# Webpad

Texteditor im Browser im Stil von **Notepad++**: Syntaxhervorhebung für viele Sprachen, Tabs, Suchen und Ersetzen, Lesezeichen, Makros – läuft komplett offline und auch als einzelne HTML-Datei auf jedem Webserver.

In ShareOS:

- **Dateien aus dem Dateibrowser** öffnen („Webpad ↗“ neben Textdateien), Strg+S speichert zurück (ShareOS 0.1.0-beta.9+).
- **Auf der Box oder auf dem eigenen Rechner speichern** (ab 1.3, ShareOS 0.1.0-beta.11+, Berechtigung `files`): Datei → *Von der Box öffnen…* / *Auf der Box speichern…* mit Ordnerauswahl; *Speichern unter…* speichert wie bisher auf dem eigenen Rechner.
- **Brücke zu anderen Apps**: WebTerm und ShareCommander schicken Dateien, Strg+S gibt sie zurück.
