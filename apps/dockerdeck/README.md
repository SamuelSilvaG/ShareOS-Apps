# DockerDeck (`dockerdeck`)

Leichtgewichtiger Docker-Container & Stack-Verwalter für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Container im Griff**: Starten, Stoppen und Neustarten von Homelab-Diensten von unterwegs.
- **Ressourcen & Ports**: Übersicht über genutzte Ports und RAM-Verbrauch pro Container.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert Container-Konfigurationen unter `system/dockerdeck_containers.json` via `ShareOS.fs`.
