# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von HabitGrid für das ShareOS-Ökosystem.
- Visuelle Monats-Heatmap (GitHub Contribution Style) mit Monats-Navigation.
- Automatische Berechnung aktueller Serien (Streaks in Tagen).
- Horizontale Sub-Header-Filterleiste nach Kategorien (Gesundheit, Produktivität, Achtsamkeit).
- Persistente Speicherung unter `habits/habits.json` via `ShareOS.fs`.
