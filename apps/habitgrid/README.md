# HabitGrid (`habitgrid`)

Minimalistischer Gewohnheiten- und Routine-Tracker für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Heatmap-Matrix**: Jeden Tag mit einem Fingertipp abhaken und Fortschritte visuell nachvollziehen.
- **Streak-Tracker**: Zeigt die aktuelle Tagesserie automatisch an.
- **Kategorien & Farben**: Individuelle Farbgebung und Emojis für jede Routine.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Daten strukturiert unter `habits/habits.json` via `ShareOS.fs`.
