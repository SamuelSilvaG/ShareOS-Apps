# SmartBudget (`smartbudget`)

Strom-, Gas- und Energiekosten-Tracker für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Zählerstände im Blick**: Erfassung von Strom-, Gas- und Wasserzählern direkt im mobilen VPN.
- **Kostenkalkulation**: Berechnet den Verbrauch und die geschätzten Kosten in Echtzeit.
- **CSV-Export**: Exportiert alle Ablesungen für Excel oder die Nebenkostenabrechnung.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert Zählerstände strukturiert unter `energy/meter_readings.json` via `ShareOS.fs`.
