# QuickUnit (`quickunit`)

Werbefreier Offline-Einheiten- & Währungsrechner für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Keine Werbung, kein Tracking**: Schnelles Umrechnen direkt im mobilen Browser ohne externe Cookie-Banner.
- **Kategorien**: Länge, Gewicht, IT-Speichergrößen (GB vs. GiB), Temperatur, Speed, Reifendruck (bar/psi) und Währungen.
- **Multi-Übersicht**: Zeigt das eingegebene Maß parallel in allen Einheiten der gewählten Rubrik an.
- **Favoriten-System**: Häufig genutzte Umrechnungen mit einem Klick aufrufen und unter `units/favorites.json` via `ShareOS.fs` speichern.
- **ShareOS 0.2.0-beta.1+ Konform**: Schnelle, responsive Bedienung unterwegs im VPN.
