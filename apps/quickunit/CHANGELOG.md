# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von QuickUnit für das ShareOS-Ökosystem.
- Werbefreier Offline-Einheitenrechner für Länge, Masse/Gewicht, Daten/Speicher, Temperatur, Geschwindigkeit, Druck/Reifen und Währungen.
- Instant-Kopierfunktion für Berechnungen in die Zwischenablage.
- Multi-Conversion-Übersicht (rechnet die Eingabe parallel in alle Einheiten der Kategorie um).
- Favoriten-Verwaltung gespeichert unter `units/favorites.json` via `ShareOS.fs`.
