# TaskBoard (`taskboard`)

Kanban- und Aufgaben-Board für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **4 Spalten**: Backlog, Todo, In Arbeit, Erledigt.
- **Drag & Drop**: Aufgaben per Maus oder Touch zwischen den Spalten verschieben.
- **Prioritäten & Tags**: Aufgaben mit Farben, Dringlichkeitsstufen und Schlagworten versehen.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Aufgaben direkt auf der Box via `ShareOS.fs` (`kanban/board.json`).
