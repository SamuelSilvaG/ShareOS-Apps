# SysMon (`sysmon`)

Leichtgewichtiger Task-Manager & System-Monitor für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Ressourcen im Blick**: CPU-Last, RAM-Verbrauch und ShareOS.fs VFS-Status.
- **Task- & Prozessübersicht**: Filter nach WebApps, ShareOS-Core und Background-Workern.
- **Aufräum-Funktion**: Beendet hängende oder inaktive Prozesse mit einem Klick.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert Snapshots persistent unter `system/sysmon_snapshots.json` via `ShareOS.fs`.
