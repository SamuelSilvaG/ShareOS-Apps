# Changelog

## 1.0.0

- Initial release for ShareOS.
- Real-time torrent and release monitoring dashboard.
- Direct integration with Transmission on ShareOS (`ShareOS.torrent` and local RPC).
- Filter management for resolution, codec, freeleech, size and regular expressions.
- IRC network & announce channel connection monitor.
- Download client management (Transmission client pre-configured).
- Native ShareOS interface theme support (light and dark mode with accent colors).
- Multi-language support: English, German and Portuguese.
