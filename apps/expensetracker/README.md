# ExpenseTracker (`expensetracker`)

Mobiles Haushaltsbuch und Ausgaben-Tracker für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Dashboard**: Einnahmen, Ausgaben und Restsaldo pro Monat im Blick.
- **Kategorien & Schnellerfassung**: Typische Rubriken (Lebensmittel, Gastronomie, Mobilität, Fixkosten) mit Emojis.
- **CSV-Export**: Generiert Tabellenkalkulations-Dateien für SheetOS oder Excel.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert Buchungen monatlich direkt auf der Box via `ShareOS.fs` (`finances/YYYY-MM.json`).
