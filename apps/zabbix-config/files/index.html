Official ShareOS Zabbix Template Zabbix 7.0+ Ready

Template designed specifically for ShareOS active monitoring. It automatically discovers storage drives, SMART metrics, software RAID arrays, box temperature, and fan telemetry.

Template Linking Requirements

  • 1 Link "Linux by Zabbix agent active" as parent template.
  • 2 Link "ShareOS by Zabbix agent active" to monitor box hardware, fan, temperature, disks, and RAID.
  • 3 Configure Host Name and HostMetadata ("ShareOS") in your auto-registration rules.

Quick Import Instructions

  • 1 Open your Zabbix Web UI and navigate to Data collection → Templates.
  • 2 Click the "Import" button at top right and upload the downloaded YAML file.
  • 3 Create or update your Host with the Host name matching this configuration.
  • 4 In Host Encryption tab, enable PSK connections and enter the exact PSK Identity and Key configured here.

ShareOS CLI & Service Audit

The configuration above translates directly into standard ShareOS Zabbix daemon commands. You can review or copy the command to execute via SSH or terminal.

echo '{"enabled":true,"server":"zabbix.example.com","hostname":"","metadata":"ShareOS","psk_identity":"","psk":"","passive":false,"port":10050,"disk_interval":30}' | shareos-zabbix set

Command Reference (`shareos-zabbix`)

Command Description
shareos-zabbix status Check agent installation, process state, and current settings
shareos-zabbix set Apply configuration from JSON payload via stdin
shareos-zabbix restart Restart the Zabbix agent daemon
shareos-zabbix logs View recent agent log entries
