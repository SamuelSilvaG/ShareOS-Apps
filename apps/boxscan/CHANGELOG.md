# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von BoxScan für das ShareOS-Ökosystem.
- Mobiler Beleg-Scan direkt über die Smartphone-Kamera (`capture="environment"`).
- Canvas-Bildverarbeitung: Schwarz-Weiß-Dokumentenkontrast, Graustufen und 90°-Rotation.
- Automatische Archivierung im Jahresordner `documents/YYYY/` via `ShareOS.fs`.
- Vollbild-Lightbox mit Download- und Löschfunktion.
