# BoxScan (`boxscan`)

Mobiler Dokumenten-Scanner & Belegablage für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Direktscan per Kamera**: Rechnungen und Quittungen unterwegs fotografieren.
- **Dokumenten-Filter**: Verwandelt Smartphone-Fotos in saubere, kontrastreiche Schwarz-Weiß- oder Graustufen-Scans.
- **Sichere Box-Ablage**: Speichert Dokumente strukturiert unter `documents/YYYY/` via `ShareOS.fs`.
- **ShareOS 0.2.0-beta.1+ Konform**: Native Berechtigung `files` und Multi-User-Trennung.
