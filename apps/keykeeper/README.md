# KeyKeeper (`keykeeper`)

Sicherer SSH-Key-, Token- & SSL-Zertifikats-Manager für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Infrastruktur im Griff**: SSH-Schlüssel, API-Token und SSL-Zertifikate sicher im VPN abrufen.
- **Ein-Klick-Kopie**: Secrets direkt in die Zwischenablage kopieren.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert Credentials strukturiert unter `security/credentials.json` via `ShareOS.fs`.
