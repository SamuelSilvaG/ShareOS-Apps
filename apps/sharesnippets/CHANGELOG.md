# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von ShareSnippets für das ShareOS-Ökosystem.
- Schnelle Erfassung von Befehlen, Skripten und Konfigurations-Dateien (Bash, Docker, Git, YAML, SQL).
- Ein-Klick-Kopierfunktion direkt in die Zwischenablage.
- Horizontale Sprachen-Filterleiste direkt unter dem Header.
- Persistente Speicherung auf der Box unter `snippets/snippets.json` via `ShareOS.fs`.
