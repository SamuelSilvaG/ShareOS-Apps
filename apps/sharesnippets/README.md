# ShareSnippets (`sharesnippets`)

Code- & Textbaustein-Manager für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Schneller Zugriff**: Häufig gebrauchte SSH-, Git- und Docker-Befehle oder YAML-Konfigurationen sofort griffbereit.
- **Ein-Klick-Kopieren**: Kopiert Codeblöcke mobil direkt in die Zwischenablage.
- **Kategorien & Tags**: Filterung nach Sprache (Bash, Docker, Git, YAML etc.) und benutzerdefinierten Tags.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Bausteine strukturiert unter `snippets/snippets.json` via `ShareOS.fs`.
