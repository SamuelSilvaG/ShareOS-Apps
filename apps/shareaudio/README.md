# ShareAudio (`shareaudio`)

Mobiles Diktiergerät und Sprachnotizen-App für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Direktaufnahme**: Sprachmemos unterwegs mit einem Klick aufnehmen.
- **Frequenz-Visualizer**: Grafische Echtzeit-Darstellung des Mikrofonsignals.
- **Speicherung auf der Box**: Sichert `.webm`-Dateien automatisch im Verzeichnis `voice_memos/` im persönlichen Home-Volume.
- **Integrierter Player**: Aufnahmen direkt in der Web-App abspielen oder herunterladen.
