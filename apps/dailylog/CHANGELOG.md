# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von DailyLog für ShareOS.
- Integrierter Monatskalender zur schnellen Tagesnavigation.
- Markdown-Editor mit Schnellbausteinen (Ziele, Dankbarkeit, Notizen) und Formatierungs-Toolbar.
- Stimmungs-Tracker (Mood-Picker) für jeden Tag.
- Autosave direkt auf die Box unter `daily_notes/YYYY-MM-DD.md` via `ShareOS.fs`.
