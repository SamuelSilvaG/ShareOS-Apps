# DailyLog (`dailylog`)

Persönliches Tagebuch & Bullet Journal für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Kalender-Navigation**: Jeder Tag hat automatisch seinen eigenen Eintrag (`daily_notes/YYYY-MM-DD.md`).
- **Bullet Journal Snippets**: Vordefinierte Bausteine für Ziele, Dankbarkeit und Erkenntnisse auf Knopfdruck.
- **Mood Tracking**: Tägliche Stimmung mit Emojis erfassen.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Notizen direkt auf der Box via `ShareOS.fs`.
