# PhotoDrop (`photodrop`)

Mobiler Foto-Upload und Galerie für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Mobile First**: Schnappschüsse unterwegs per Drag & Drop oder über die Kamera direkt auf die heimische Box laden.
- **Automatisches Sortieren**: Legt Fotos chronologisch im Verzeichnis `photos/YYYY-MM/` im persönlichen Home-Volume ab.
- **Lightbox-Viewer**: Fotos in voller Auflösung betrachten und verwalten.
- **ShareOS 0.2.0-beta.1+ Konform**: Native Integration von `ShareOS.fs` und Berechtigung `files`.
