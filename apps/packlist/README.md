# PackList (`packlist`)

Smarte Reise-, Camping- und Checklisten-App für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Reise-Checklisten**: Vordefinierte Vorlagen für Sommerurlaub, Outdoor/Camping und Technik/Homeoffice.
- **Fortschrittsbalken**: Zeigt in Prozent und Anzahl an, wie viel bereits eingepackt wurde.
- **Kategorien**: Automatische Gruppierung nach Kleidung, Dokumenten, Elektronik etc.
- **Wiederverwendbar**: Ein-Klick-Reset aller Haken vor der nächsten Reise.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Checklisten strukturiert unter `checklists/lists.json` via `ShareOS.fs`.
