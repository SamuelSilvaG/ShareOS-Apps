# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von PackList für das ShareOS-Ökosystem.
- Smarte Packlisten für Reisen, Camping und Technik mit Fortschrittsanzeige in Echtzeit.
- Kategoriensortierung (Dokumente, Kleidung, Elektronik, Hygiene, Outdoor).
- Schneller Haken-Reset („🔄 Reset“) für wiederkehrende Reisen und Urlaube.
- Persistente Speicherung auf der Box unter `checklists/lists.json` via `ShareOS.fs`.
