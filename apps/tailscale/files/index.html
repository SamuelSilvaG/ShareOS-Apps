How to access your ShareOS box from anywhere

With Tailscale active, your box receives a dedicated private IP (100.x.y.z) and a secure end-to-end encrypted name without opening any ports on your router.

Device OS Tailscale IP Status Actions
Step 1 Connect your other devices
Install the official Tailscale app on your computer, phone, or tablet (Windows, macOS, Linux, Android, iOS) and sign in with the same account.
Step 2 ShareOS Web Interface
Open your web browser on any network (external Wi-Fi, cellular 4G/5G) and navigate to the box IP:
http://100.86.14.92:80/
Step 3 Network File Sharing (SMB / Windows / Mac)
Connect your network drive in Windows File Explorer or Mac Finder over the VPN:
On Windows: enter in File Explorer address bar:
\\100.86.14.92\
On Mac: Finder → Connect to Server (Cmd+K):
smb://100.86.14.92
Step 4 Transmission & Downloads
Monitor and manage your Transmission torrent downloads remotely in the browser:
http://100.86.14.92:8081/apps/transmission/
Step 5 Secure SSH Terminal
Open a secure SSH shell without exposing port 22 to the public internet:
ssh root@100.86.14.92
