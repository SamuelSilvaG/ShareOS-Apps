# TinyPDF (`tinypdf`)

Leichtgewichtiger PDF-Viewer & Formular-Helfer für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Dokumente im VPN öffnen**: Durchsucht das persönliche Box-Volumen nach `.pdf`-Dateien und zeigt sie an.
- **Digitale Unterschrift**: Integriertes Signaturpad zum Unterzeichnen von Belegen und Verträgen direkt auf dem Smartphone oder Tablet.
- **ShareOS 0.2.0-beta.1+ Konform**: Perfekt integriert in das VFS Dateisystem.
