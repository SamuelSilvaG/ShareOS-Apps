# HomePing (`homeping`)

Homelab Status-Monitor für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Server & Container im Blick**: Überwacht Proxmox, TrueNAS, Home Assistant oder Docker Stacks im Heimnetz.
- **Latenz & Ping**: Misst die Antwortzeit in Millisekunden und zeigt den Online/Offline-Status auf einen Blick.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Nodes strukturiert unter `system/homeping_nodes.json` via `ShareOS.fs`.
