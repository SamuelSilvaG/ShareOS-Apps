# ShareStash (`sharestash`)

Pocket / Raindrop.io ähnlicher Bookmark- und Read-Later-Manager für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Read-Later & Archiv**: Links unterwegs speichern, als ungelesen markieren oder ins Archiv legen.
- **Tag-System**: Schnelle Filterung nach Themen (z. B. `#dev`, `#linux`, `#rezepte`).
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert die Lesezeichen direkt auf der Box via `ShareOS.fs` (`bookmarks/bookmarks.json`).
