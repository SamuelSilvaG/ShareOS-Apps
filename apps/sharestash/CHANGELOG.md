# Changelog

## [1.0.1] - 2026-10-23
### Behoben
- Auf dem Handy bricht die Kopfleiste um, statt seitlich zu scrollen: Suche bzw. Mitte in eigener Zeile, Kontoname gekürzt, Versionsnummer ausgeblendet.
- Auf dem Handy stehen Filter und Tags über den Lesezeichen (seitlich scrollbar), die Lesezeichen bekommen die ganze Breite.

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von ShareStash für das ShareOS-Ökosystem.
- Pocket & Raindrop Look mit Tag-Filterung, Ungelesen- und Archiv-Status.
- Persistente Speicherung auf der Box unter `bookmarks/bookmarks.json` via `ShareOS.fs`.
- Responsive Modal-Maske zum Hinzufügen und Bearbeiten von Links.
