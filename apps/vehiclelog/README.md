# VehicleLog (`vehiclelog`)

Digitales Fahrtenbuch, Tank- & Lade-Tracker für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Fahrten- & Tankbuch**: Schnelle Erfassung von Betankungen, Ladevorgängen, Dienstfahrten und Inspektionen direkt im mobilen Browser.
- **Automatische Verbrauchsanalyse**: Errechnet Durchschnittsverbrauch pro 100 km und Kilometerkosten in Echtzeit.
- **CSV-Export**: Exportiert das vollständige Fahrtenbuch mit einem Klick für Excel oder die Steuer.
- **Sub-Header Filter**: Schnelles Umschalten zwischen Fahrten, Tankstopps und Service.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert alle Einträge strukturiert unter `vehicle/logbook.json` via `ShareOS.fs`.
