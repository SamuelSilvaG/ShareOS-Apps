# RecipeVault (`recipevault`)

Private Rezeptsammlung & Kochbuch mit dynamischem Portionsrechner für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **Kochbuch für unterwegs**: Alle Lieblingsrezepte ohne Werbung und Tracker im mobilen VPN abrufbar.
- **Portionsrechner**: Mengenangaben passen sich bei Klick auf +/- Portionen sofort automatisch an.
- **Einkaufslisten-Kopierer**: Zutaten mit einem Klick formatiert in die Zwischenablage kopieren.
- **Sub-Header Filter**: Schnelles Filtern nach Hauptgerichten, schnellen Rezepten, vegetarisch und Desserts.
- **ShareOS 0.2.0-beta.1+ Konform**: Speichert Rezepte strukturiert unter `recipes/recipes.json` via `ShareOS.fs`.
