# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von RecipeVault für das ShareOS-Ökosystem.
- Digitales Kochbuch mit Rezeptverwaltung, Zutatenlisten und Zubereitungsschritten.
- Dynamischer Portionsrechner (Mengen skalieren bei Klick auf +/-).
- Ein-Klick-Export der Zutatenliste als Einkaufszettel in die Zwischenablage.
- Horizontale Sub-Header-Filterleiste nach Rezept-Kategorien.
- Persistente Speicherung unter `recipes/recipes.json` via `ShareOS.fs`.
