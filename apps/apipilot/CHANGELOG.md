## 1.0.0

- First version in the ShareOS app store: REST and GraphQL client with methods, query parameters, headers, bearer/basic auth, JSON/GraphQL/form/text bodies, response status, time, size and headers, cURL and fetch code, history.
- Responses are saved on the box with its file dialog (permission `files`), downloaded, or opened in Webpad (saving there takes the text back).
- ShareOS look (light/dark, accent colour); storage per account.
