# ShareFeed (`sharefeed`)

Minimalistischer RSS- und News-Reader für das [ShareOS-Apps](https://github.com/UniqueDroid/ShareOS-Apps) Ökosystem.

## Features
- **RSS & Atom Reader**: Nachrichten, Blogs und Tech-Feeds unterwegs abrufen und im aufgeräumten 3-Spalten-Layout lesen.
- **Offline & Box-Sync**: Artikel werden direkt auf der Box gespeichert (`feeds/feeds.json`), sodass du auch im Zug ohne Netz weiterlesen kannst.
- **Favoriten**: Wichtige Artikel mit einem Stern markieren.
- **ShareOS 0.2.0-beta.1+ Konform**: Native Integration von `ShareOS.fs` und Berechtigung `files`.
