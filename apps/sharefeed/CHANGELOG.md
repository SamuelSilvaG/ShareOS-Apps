# Changelog

## [1.0.1] - 2026-10-26
### Geändert
- Folgt den Farben von ShareOS: hell/dunkel und Akzentfarbe (bisher immer das eigene dunkle Farbschema); das Layout bleibt.
- Englisch, wenn die ShareOS-Oberfläche nicht auf Deutsch steht ([#74](https://github.com/UniqueDroid/ShareOS/issues/74)).

## [1.0.0] - 2026-10-23
### Hinzugefügt
- Erstveröffentlichung von ShareFeed für ShareOS.
- RSS 2.0 & Atom Feed-Unterstützung mit Mehrspalten-Reader (Feeds, Artikelliste, Lesebereich).
- Vollständige Speicherung auf der Box unter `feeds/feeds.json` via `ShareOS.fs`.
- Offline-Caching der Artikel und Favoriten-Markierung (Sternchen).
