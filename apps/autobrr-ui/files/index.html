Transmission Handover Integration

How It Works

autobrr runs as a single service for the whole box. When a matching torrent is captured, it is placed into a secure hand-over folder with permissions 2770. The Transmission daemon of the designated user monitors this folder and automatically starts downloading.

Native autobrr Web Interface (Port 7474)

autobrr includes its full native web dashboard. By default, it binds only to 127.0.0.1 for maximum security and RAM efficiency.

🌐 Open autobrr Web Interface http://...:7474
DNS-320L Tip: Keep the web interface disabled when not in use to free up CPU cycles and socket handles on the Kirkwood processor.
